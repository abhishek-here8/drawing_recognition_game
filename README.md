# 🎮 AI Recognition Game
 
An interactive browser-based game where you draw a character — letter, digit, or symbol — and Claude's AI vision model guesses what it is in real time.
 
---
 
## ✨ Features
 
- **Freehand Drawing Canvas** — smooth, responsive drawing with mouse or touch
- **AI-Powered Recognition** — uses Claude's vision API to analyze your drawing
- **Supports All Characters** — digits (0–9), uppercase & lowercase letters (A–Z, a–z), and symbols (`@`, `#`, `$`, `%`, `&`, `!`, `?`, `+`, `=`, `*`, `~`, and more)
- **Confidence Score** — animated bar showing how confident the AI is
- **Alternative Guesses** — shows up to 3 other possible characters
- **Score Tracker** — tracks total guesses, correct answers, and your current streak
- **Quick Draw** — click any character chip to auto-draw it as a template
- **Drawing Tools** — 5 colors, 3 brush sizes (S/M/L), and an eraser
- **No Installation** — single `.html` file, runs in any modern browser
